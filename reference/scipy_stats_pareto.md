# Pareto distribution

Ports of `jax.scipy.stats.pareto`.

## Usage

``` r
scipy_stats_pareto_logpdf(x, b, loc = 0L, scale = 1L)

scipy_stats_pareto_pdf(x, b, loc = 0L, scale = 1L)

scipy_stats_pareto_cdf(x, b, loc = 0L, scale = 1L)

scipy_stats_pareto_logcdf(x, b, loc = 0L, scale = 1L)

scipy_stats_pareto_logsf(x, b, loc = 0L, scale = 1L)

scipy_stats_pareto_sf(x, b, loc = 0L, scale = 1L)

scipy_stats_pareto_ppf(q, b, loc = 0L, scale = 1L)
```

## Arguments

- x:

  Values.

- b:

  Shape parameter.

- loc:

  Location.

- scale:

  Scale.

- q:

  Probabilities.

## Value

An array.
