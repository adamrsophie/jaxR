# Round to a number of decimals

Port of `jnp.around` (an alias of `jnp.round`): rounds half to even;
integers are returned unchanged.

## Usage

``` r
jnp_around(a, decimals = 0L, out = NULL)
```

## Arguments

- a:

  Array.

- decimals:

  Number of decimals (static integer).

- out:

  Not supported (must be `NULL`).

## Value

An array.
