# Rebuild a pytree from a treedef and leaves

Rebuild a pytree from a treedef and leaves

## Usage

``` r
tree_unflatten(treedef, leaves)
```

## Arguments

- treedef:

  A treedef from
  [`tree_flatten()`](https://adamrsophie.github.io/jaxR/reference/tree_flatten.md).

- leaves:

  A list of leaves.
