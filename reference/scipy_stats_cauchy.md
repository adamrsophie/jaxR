# Cauchy distribution

Ports of `jax.scipy.stats.cauchy`.

## Usage

``` r
scipy_stats_cauchy_logpdf(x, loc = 0L, scale = 1L)

scipy_stats_cauchy_pdf(x, loc = 0L, scale = 1L)

scipy_stats_cauchy_cdf(x, loc = 0L, scale = 1L)

scipy_stats_cauchy_logcdf(x, loc = 0L, scale = 1L)

scipy_stats_cauchy_sf(x, loc = 0L, scale = 1L)

scipy_stats_cauchy_logsf(x, loc = 0L, scale = 1L)

scipy_stats_cauchy_isf(q, loc = 0L, scale = 1L)

scipy_stats_cauchy_ppf(q, loc = 0L, scale = 1L)
```

## Arguments

- x:

  Values.

- loc:

  Location.

- scale:

  Scale.

- q:

  Probabilities.

## Value

An array.
