# Sum along diagonals

Port of `jnp.trace`.

## Usage

``` r
jnp_trace(a, offset = 0L, axis1 = 0L, axis2 = 1L, dtype = NULL, out = NULL)
```

## Arguments

- a:

  Array of rank at least two.

- offset:

  Diagonal offset.

- axis1, axis2:

  Axes of the matrices (0-based).

- dtype:

  Optional accumulation dtype.

- out:

  Not supported.

## Value

An array.
