# Image resize methods

Port of `jax.image.ResizeMethod`: the method names accepted by
[`image_resize()`](https://adamrsophie.github.io/jaxR/reference/image_resize.md)
and
[`image_scale_and_translate()`](https://adamrsophie.github.io/jaxR/reference/image_scale_and_translate.md).
Strings work too: `"nearest"`, `"linear"` (`"bilinear"`, `"trilinear"`,
`"triangle"`), `"lanczos3"`, `"lanczos5"`, `"cubic"` (`"bicubic"`,
`"tricubic"`), `"cubic-pytorch"` (`"bicubic-pytorch"`) and `"area"`.

## Usage

``` r
image_ResizeMethod
```
