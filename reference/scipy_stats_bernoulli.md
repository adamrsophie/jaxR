# Bernoulli distribution

Ports of `jax.scipy.stats.bernoulli`.

## Usage

``` r
scipy_stats_bernoulli_logpmf(k, p, loc = 0L)

scipy_stats_bernoulli_pmf(k, p, loc = 0L)

scipy_stats_bernoulli_cdf(k, p)

scipy_stats_bernoulli_ppf(q, p)
```

## Arguments

- k:

  Outcomes.

- p:

  Success probability.

- loc:

  Location.

- q:

  Probabilities.

## Value

An array.
