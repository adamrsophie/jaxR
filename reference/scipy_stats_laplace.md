# Laplace distribution

Ports of `jax.scipy.stats.laplace`.

## Usage

``` r
scipy_stats_laplace_logpdf(x, loc = 0L, scale = 1L)

scipy_stats_laplace_pdf(x, loc = 0L, scale = 1L)

scipy_stats_laplace_cdf(x, loc = 0L, scale = 1L)
```

## Arguments

- x:

  Values.

- loc:

  Location.

- scale:

  Scale.

## Value

An array.
