# Test dtype categories

Port of `jnp.issubdtype` for the abstract categories `"floating"`,
`"integer"`, `"signedinteger"`, `"unsignedinteger"`,
`"complexfloating"`, `"inexact"`, `"number"`, `"bool"`.

## Usage

``` r
issubdtype(arg1, arg2)
```

## Arguments

- arg1:

  A dtype or value.

- arg2:

  A dtype or category name.

## Value

Logical scalar.
