# Multinomial distribution

Ports of `jax.scipy.stats.multinomial`.

## Usage

``` r
scipy_stats_multinomial_logpmf(x, n, p)

scipy_stats_multinomial_pmf(x, n, p)
```

## Arguments

- x:

  Counts (integer typed), categories along the last axis.

- n:

  Number of trials (integer typed).

- p:

  Category probabilities.

## Value

An array.
