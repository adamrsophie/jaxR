# Index of the maximum along an axis

Index of the maximum along an axis

## Usage

``` r
lax_argmax(operand, axis, index_dtype = "int32")

lax_argmin(operand, axis, index_dtype = "int32")
```

## Arguments

- operand:

  Array.

- axis:

  0-based axis.

- index_dtype:

  Integer dtype of the result.
