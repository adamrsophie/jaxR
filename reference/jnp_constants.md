# Constants

The constants of `jax.numpy`: `jnp_pi`, `jnp_e`, `jnp_euler_gamma`,
`jnp_inf`, `jnp_nan` (R doubles, weakly typed when converted) and
`jnp_newaxis` (the
[newaxis](https://adamrsophie.github.io/jaxR/reference/sl.md) index
object).

## Usage

``` r
jnp_pi

jnp_e

jnp_euler_gamma

jnp_inf

jnp_nan

jnp_newaxis
```
