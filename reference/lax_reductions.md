# lax reductions

lax reductions

## Usage

``` r
lax_reduce_sum(operand, axes)

lax_reduce_prod(operand, axes)

lax_reduce_max(operand, axes)

lax_reduce_min(operand, axes)

lax_reduce_and(operand, axes)

lax_reduce_or(operand, axes)

lax_reduce_xor(operand, axes)
```

## Arguments

- operand:

  Array.

- axes:

  0-based axes to reduce.
