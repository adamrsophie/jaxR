# Convert to a jax array

Convert to a jax array

## Usage

``` r
jnp_asarray(a, dtype = NULL, copy = NULL)

jnp_array(a, dtype = NULL, copy = TRUE, ndmin = 0L)
```

## Arguments

- a:

  R data, array, or nested list of scalars.

- dtype:

  Optional dtype.

- copy:

  Ignored.

- ndmin:

  Minimum rank of the result: unit dimensions are prepended as needed.
