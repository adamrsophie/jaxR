# Negative binomial distribution

Ports of `jax.scipy.stats.nbinom`.

## Usage

``` r
scipy_stats_nbinom_logpmf(k, n, p, loc = 0L)

scipy_stats_nbinom_pmf(k, n, p, loc = 0L)
```

## Arguments

- k:

  Outcomes.

- n:

  Number of successes.

- p:

  Success probability.

- loc:

  Location.

## Value

An array.
