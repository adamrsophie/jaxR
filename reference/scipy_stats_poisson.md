# Poisson distribution

Ports of `jax.scipy.stats.poisson`.

## Usage

``` r
scipy_stats_poisson_logpmf(k, mu, loc = 0L)

scipy_stats_poisson_pmf(k, mu, loc = 0L)

scipy_stats_poisson_cdf(k, mu, loc = 0L)

scipy_stats_poisson_entropy(mu, loc = 0L)
```

## Arguments

- k:

  Outcomes.

- mu:

  Rate.

- loc:

  Location.

## Value

An array.
