# Select elements

Three-argument form of `jnp.where`.

## Usage

``` r
jnp_where(condition, x = NULL, y = NULL, size = NULL, fill_value = NULL)
```

## Arguments

- condition:

  Boolean array.

- x, y:

  Values where condition is true / false.

- size, fill_value:

  One argument form only; see
  [`jnp_nonzero()`](https://adamrsophie.github.io/jaxR/reference/jnp_nonzero.md).
