# Inner products

Inner products

## Usage

``` r
jnp_vdot(a, b, precision = NULL, preferred_element_type = NULL)

jnp_inner(a, b, precision = NULL, preferred_element_type = NULL)

jnp_outer(a, b, out = NULL)
```

## Arguments

- a, b:

  Arrays.

- precision, preferred_element_type:

  See
  [`lax_dot_general()`](https://adamrsophie.github.io/jaxR/reference/lax_dot_general.md).

- out:

  Unsupported; must be `NULL`.
