# Beta binomial distribution

Ports of `jax.scipy.stats.betabinom`.

## Usage

``` r
scipy_stats_betabinom_logpmf(k, n, a, b, loc = 0L)

scipy_stats_betabinom_pmf(k, n, a, b, loc = 0L)
```

## Arguments

- k:

  Outcomes.

- n:

  Number of trials.

- a, b:

  Shape parameters.

- loc:

  Location.

## Value

An array.
