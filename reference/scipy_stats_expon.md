# Exponential distribution

Ports of `jax.scipy.stats.expon`.

## Usage

``` r
scipy_stats_expon_logpdf(x, loc = 0L, scale = 1L)

scipy_stats_expon_pdf(x, loc = 0L, scale = 1L)

scipy_stats_expon_cdf(x, loc = 0L, scale = 1L)

scipy_stats_expon_logcdf(x, loc = 0L, scale = 1L)

scipy_stats_expon_logsf(x, loc = 0L, scale = 1L)

scipy_stats_expon_sf(x, loc = 0L, scale = 1L)

scipy_stats_expon_ppf(q, loc = 0L, scale = 1L)
```

## Arguments

- x:

  Values.

- loc:

  Location.

- scale:

  Scale.

- q:

  Probabilities.

## Value

An array.
